내가 만든 앱을 검사해 보세요

앱의 코드 폴더에서 알려진 보안 문제를 찾고, 발견 항목과 다음 조치를 확인하세요.

앱의 코드가 들어 있는 폴더를 찾아 선택하세요.

함께 제공된 예제 앱으로 검사와 결과 보기를 체험하세요.

검사 순서

  1. 내 앱이나 예제를 검사합니다.
  2. 발견 항목과 근거를 검토합니다.
  3. 안내에 따라 조치한 뒤 다시 검사합니다.

기본 검사에는 앱의 코드 폴더가 필요합니다. 웹사이트 주소만으로는 검사할 수 없으며, 컴퓨터 전체의 바이러스를 검사하지 않습니다.

앱의 코드 폴더를 선택하세요

앱의 파일이 들어 있는 폴더 전체를 선택하세요. 이 예시에서는 my-app 폴더를 선택합니다.

AI 빌더에서 앱을 만들었다면 코드를 ZIP으로 내보내거나 다운로드하세요. ZIP의 압축을 풀고 코드가 들어 있는 폴더를 선택하세요.

검사 권한이 있는 HTTP(S) URL을 입력하세요. 쿼리, 프래그먼트, 로그인 정보는 제외하세요.

선택한 AI 도구가 프로젝트 소스와 관련 정보를 모델 제공업체에 전송할 수 있습니다. 계정의 API 또는 사용량 요금이 부과될 수 있습니다.
